# Investigación de las ejecuciones fallidas de Android

Se revisaron los registros de GitHub Actions y los XML de pruebas. El job de publicación depende del job de pruebas; un error en el emulador o en el script de validación impide publicar aunque `assembleRelease` haya compilado correctamente.

| Ejecución | Evidencia en el registro | Causa y corrección |
| --- | --- | --- |
| [1](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37150993636) y [2](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37151140641) | `Failed to find package 'tools'` en setup-android | La acción intentaba instalar un paquete obsoleto del SDK. Se pide explícitamente `platform-tools` y luego el SDK y build-tools requeridos. La ejecución 3 completó el build 1.8.1. |
| [4](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37164239050) | Espacio disponible 7299,44 MB, necesarios 7372,80 MB | Mismo problema de disco del emulador que volvió a aparecer en la ejecución 8. Reducir solo el disco declarado no bastó; se liberó espacio del runner. |
| [7](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37165079277) | 3 pruebas fallidas: nodo de opciones ausente, `performScrollTo()` y excepción `ZipException` frente a `IllegalArgumentException` | Se ampliaron las áreas táctiles del menú, se desplaza la lista antes de buscar sus elementos y se espera la interfaz. El rechazo de ZIP peligrosos puede ocurrir en Android antes de la comprobación de la app; la prueba admite ambos tipos de rechazo y sigue verificando que no se importen archivos. |
| [8](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37170727814) | `Not enough space to create userdata partition`: disponibles 7310,63 MB, necesarios 7372,80 MB | El emulador estándar no podía arrancar. Se liberan SDK preinstalados que esta app no usa antes de iniciarlo. |
| [9](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37171188818) | 30 pruebas debug completadas; release inicia 0 y falla con `NoClassDefFoundError: androidx/tracing/Trace` | R8 eliminó APIs del APK principal que compartía el ejecutor de pruebas. Las reglas de conservación se aplican exclusivamente con `-PtestMinified`. Se comprueba aparte el APK normal sin esas reglas. |
| [11](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37172228143) | `RootViewWithoutFocusException` al preparar una captura y espera de `1 coincidencias` | El ayudante intentaba cerrar un teclado desde una ventana sin foco. Usa ahora las ventanas accesibles de Android. La interfaz pasó a mostrar el singular correcto; las aserciones se actualizan conjuntamente. |
| [12](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37172991416) | Una segunda aserción seguía buscando `1 coincidencias` | La primera corrección del test quedó incompleta. Se revisaron todas las apariciones, incluida la acción de pulsar el resultado. Fue un error en la prueba. |
| [14](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37174230674) | XML: debug 30/30 y release instrumentada 12/12, sin fallos; `assembleRelease` termina correctamente; después `FileNotFoundException: /home/runner/.android/debug.keystore` | El script adicional suponía una ruta para la clave temporal. Consulta ahora `:app:signingReport` para usar el almacén configurado por Gradle. La firma se verificó localmente comparando el certificado con el del APK debug. |

La corrección de la ruta no introduce otra clave de distribución: solo firma una copia temporal en el laboratorio del emulador. El archivo temporal se elimina y no se publica. La firma de la versión entregable sigue dependiendo de la clave original, según COMPILACION-Y-FIRMA.md.

También se revisó la comprobación de la interfaz del APK normal: los controles del lector se ocultan a los cinco segundos, por lo que el script los vuelve a mostrar cuando es necesario antes de pulsar las herramientas. Se mantiene la comprobación del texto real del EPUB dentro del WebView.

La [ejecución 15](https://github.com/Keiiiiken/Nova-Reader/actions/runs/37175830167) aprobó las 42 pruebas, la comprobación adicional del APK normal, la compilación, lint y la publicación. Ambos jobs terminaron correctamente. Se publicó el [prerelease 1.9.0 · build 15](https://github.com/Keiiiiken/Nova-Reader/releases/tag/v1.9.0-build.15), sin firma original. El resultado y el SHA-256 del APK se recogen en VALIDACION-1.9.0.md.
